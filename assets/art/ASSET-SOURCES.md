# 인게임 아트 출처

`assets/art/asset-manifest.json`의 프롬프트와 `style/style-guide.md`, `style/anchor.png`를
생성·재생성 기준으로 사용한다. 외부 스프라이트를 저장소에 복사하지 않는다.

## 성장 단계 아트

- `stage_sprout.png`, `stage_sapling.png`: 기존 Happy Farm 생성 아트 세트
- `stage_budding.png`, `stage_mature.png`: 2026-07-23 Codex built-in `gpt-image-2`로 생성
- 스타일 출처: 저장소의 `style/anchor.png`와 `style/style-guide.md`
- 라이선스: Seorilabs 프로젝트용 원본 생성물

OpenGameArt의 LPC Crops 이미지는 성장 단계 구분 아이디어를 확인하는 시각 참고 자료로만
사용했으며, 픽셀·프레임·구성 요소를 복제하거나 포함하지 않았다.
