# 타이틀 화면 방향과 시작 동작

2026-10-05. 기준 코드: `9bcecf45642cb0287e7b5d9711981da39ceaa33c`.

현재 상태: **사용자가 A — 아침 농장을 선택했으며 mobile·AIT 구현과 Galaxy Note9 검수를 완료했다.** [시안과 실행 화면 비교](runtime/target-vs-runtime.png) · [검증 기록](qa.md). iOS와 토스 앱 안의 실제 실행 검수는 출시 후보 단계에 남아 있다.

## 기준

- 기존 [Warm Wood 방향](../main-screen-direction.md)의 크림·나무 톤과 초록 주요 버튼을 잇는다.
- 소재와 재질은 [기존 클레이 아트 가이드](../../../assets/art/style/style-guide.md)와 `anchor.png`를 따른다. 기존 anchor는 변경하지 않았다.
- 로고 → 농장의 대표 모습 → 준비 상태와 시작 버튼 순서로 읽는다. 타이틀에 상점·미션·보상을 추가하지 않는다.
- 첫 실행과 앱 프로세스의 새 시작에 표시한다. 이미 시작한 세션의 백그라운드 복귀에는 반복하지 않는다.

## 비교 시안

[비교 이미지](reference/title-options-ko.png) · [상태·언어·크기 전환이 가능한 HTML](reference/title-options.html)

| 방향 | 표현 | 구현할 요소 |
| --- | --- | --- |
| A — 아침 농장 | 화면 전체를 채운 농장 풍경, 초록·주황 2단 로고, 깊은 원경 | 배경 cover 크롭, 외곽선·입체 로고, 아래쪽 읽기용 밝은 면 |
| B — 작은 농장 | 크림 배경의 농장 디오라마, 나무 간판 로고 | 배경 비율별 크롭, 나무 간판·크림 로고, 초록 주요 버튼 |

두 시안의 실제 문구와 주요 행동은 같다. 제목은 기존 catalog의 `행복 농장` / `Happy Farm`, 장르 표기는 기존 `Tycoon`이다. 신규 문구는 `농장 준비 완료` / `Your farm is ready`, `농장으로 가기` / `Enter Farm`이다. 저장소가 지원하는 **8개 locale 모두**에 추가했다. 시안 HTML의 문구는 검수용이며 제품 catalog를 대신하지 않는다.

배경 생성에는 Codex built-in gpt-image-2를 사용했다. 기존 anchor는 재질·색상 참조로만 첨부했다. 원본 배경과 정확한 프롬프트는 [generation-manifest.json](generation-manifest.json)에 보존했다. 텍스트와 입력 영역은 배경에 구워 넣지 않았으며 HTML의 실제 폰트 레이어로 조립했다.

## 구현된 시작 흐름

mobile `App.tsx`와 AIT `src/pages/index.tsx`에 같은 `FarmStartup`을 연결했다. 준비된 저장을 `startupSnapshot`으로 전달하고, 사용자가 시작 버튼을 누른 뒤 `FarmGame`을 마운트한다. 농장 화면의 시트·온보딩·게임 틱과 광고 hook은 진입 후에 시작한다. mobile의 광고 동의 조회도 시작 입력 이후로 옮겼다.

1. 타이틀을 먼저 그린 뒤 로컬 저장과 설정 읽기를 시작한다.
2. 완료된 작업 수로 준비 상태를 표시한다. 시간에 따라 증가하는 가짜 백분율과 표시 목적의 지연을 넣지 않는다.
3. 필수 로컬 준비 완료 후 시작 버튼을 활성화한다. 광고·분석·계정 네트워크 응답을 시작 가능 조건에 넣지 않는다.
4. 시작 버튼 입력 후 준비된 저장을 농장으로 넘기고 기존 복귀 정산·온보딩을 이어간다. 저장을 이중 복원하거나 타이틀 체류 시간을 농장 플레이 시간으로 계산하지 않는다.
5. 실제 읽기 실패는 오류·재시도 상태로 처리한다. 실패를 임의의 새 농장 저장으로 덮어쓰지 않는다.
6. 배경과 읽기용 그라데이션은 mobile에 파일로, AIT에 data URI로 포함한다. 타이틀의 첫 표시는 이미지 서버 응답을 기다리지 않는다. `pnpm check:title-art`가 두 플랫폼의 바이트와 원본 일치를 검사하며 기존 architecture 검증에도 연결했다.

`FarmStartup`이 실제 설정 읽기 1단계와 저장·마지막 접속 읽기 1단계의 완료 수를 표시한다. `FarmGame`은 전달받은 snapshot을 사용해 같은 저장을 다시 읽지 않으며 기존 migration과 복귀 정산을 실행한다. `createFarmPersistence`의 읽기 예외는 타이틀까지 전달한다. 저장이 없는 신규 농장만 초기 상태로 만들고, 읽기 실패·손상된 JSON을 새 저장으로 덮지 않는 회귀 검증을 추가했다. 기존 1회 원본 저장 백업은 유지했다.

## 시안 검수 결과

[layout-review.json](reference/layout-review.json)에 10개 조건의 영역 좌표와 텍스트 넘침 결과가 있다.

- A/B 각각: 한국어 준비 완료 390×844, 영어 준비 완료 320×568, 한국어 준비 중 390×844, 영어 오류 390×844, 영어 큰 글자 390×844.
- 10개 조건에서 로고·상태·진행 표시·주요 버튼·제작사 표기가 화면 안에 있고 가로 텍스트 넘침이 없었다.
- 작은 화면의 영문 로고와 버튼, 오류 문구를 실제 Chromium 렌더 이미지로 확인했다.
- 준비 중 버튼은 disabled, 오류 상태는 재시도 문구와 갈색 진행 상태다. 버튼 눌림 외형은 HTML에 정의되어 있다.
- HTML 상태 전환은 **디자인 검수용 모의 상태**다. 실제 컴포넌트의 읽기·재시도·중복 입력·저장 보존은 자동 테스트로, 시작 입력과 앱 복귀는 Note9 제품 화면으로 검증했다. 느린 읽기·오류·언어·큰 글자는 같은 컴포넌트에 검수용 persistence를 넣어 기기에서 확인했다. 상세 구분은 [qa.md](qa.md)에 있다.
- 배경은 정적으로 제작했다. 신규 모션 승인이나 성능 검증을 주장하지 않는다.

배경 원본 A/B와 이전 비교 렌더는 선택 근거로 보존했다. 제품 bundle에는 A만 포함한다. Android 시각·동작 검증과 AIT 로컬 build는 완료했으며, iOS·실제 토스 앱 검수 및 마켓 업로드·제출·공개 배포는 별도 출시 단계다.
