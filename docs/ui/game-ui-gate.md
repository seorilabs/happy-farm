# 게임 UI 필수 재료 게이트 (AC-14)

2026-11-26 게임 UI 개편(#606, 설계 `docs/design/2026-11-26-game-ui-first-session/`)의 필수 재료 9항목 점검표다. 기준은 `game-ui-design` 스킬의 `required-ingredients.md`다. 정적 점검 스크립트 `ui_gate.py`는 Godot 전용이라 이 저장소(React Native)에는 쓰지 않고, 코드 위치와 실행 화면으로 판정했다. 실행 화면 판정은 재설계 검수 회차 보고서(`docs/qa/2026-11-26-game-ui-first-session/`)를 따른다.

| # | 항목 | 상태 | 근거 |
|---|---|---|---|
| 1 | 디스플레이 서체와 본문 서체 | 통과 | mobile은 숫자와 라틴 문자에 Baloo 2 ExtraBold(`assets/fonts/Baloo2-ExtraBold.ttf`, iOS `UIAppFonts`, Android `assets/fonts`), 본문은 시스템 서체다. `FarmArt.displayFontFamily`와 `GameText`, `useDisplayFontStyle`(#613). 앱인토스는 커스텀 서체를 확인하지 못해 시스템 굵은 글씨에 아래 띠를 준다(사용자 결정 "숫자·라틴만 서체 추가") |
| 2 | 그린 스킨 | 부분 통과 | primary, secondary, chip, panel 4종을 3분할 이미지로 그린다(`assets/art/ui/runtime/`, `SkinFrame`). 눌림과 비활성은 별도 이미지 대신 덮개로 만든다(`SKIN_PRESSED_SHADE`, `SKIN_DISABLED_SHADE`). 헤더 칩, 목표 칩, 일괄 행동, 구역 칩, 가기 버튼에 적용했다. 팝업 프레임 스킨은 만들지 않았고 시트와 안내 팝업은 Warm Wood 코드 스타일이다. 시트 12종 재스킨을 다음 차수로 미룬 승인 범위(사용자 결정 "메인+첫 세션+잦은 보상")에 따른 것이다 |
| 3 | 팝업 진입·퇴장 모션 | 통과 | 시트는 딤 페이드와 스프링 오버슈트로 열리고 닫힌다. 안내 팝업은 `usePopInStyle`로 커지며 등장한다(#609) |
| 4 | 모든 버튼 효과음 | 통과 | `GamePressable`이 탭음(`sfx_tap`, 0.35 음량)과 눌림 상태를 붙이고 설정의 효과음 끄기를 따른다. 밭 칸은 수확·심기 효과음이 따로 있어 탭음을 겹치지 않는다(#609) |
| 5 | 보상 3단계 연출 | 통과 | 기대("+금액"이 누른 자리에서 튀어 오름), 충격(코인 8개 흩어짐과 보상 효과음), 정착(보이는 골드 칩으로 날아가 숫자 카운트업). 미션, 출석, 복귀 1배·2배, 광고 골드, 첫 수확, 룰렛에 적용(#611, #612, #617). 첫 수확은 리본·빛살·큰 코인·카운트업·확인 하나인 보상 팝업(`RewardPopup`)을 함께 띄운다. 출석은 확인을 눌러 닫을 때, 복귀 전면 광고는 연출이 끝난 뒤에 낸다(1회차 #5, #6). 동작 줄이기면 효과음과 숫자만 남긴다 |
| 6 | 파티클 | 통과 | 수확 파티클(기존)과 보상 코인 버스트(`RewardBurstLayer`) |
| 7 | HUD 레이어 | 통과 | 게임 층(밭), HUD 층(헤더, 도구 줄, 하단 탭 바), 오버레이 층(첫 수확 스포트라이트 z20, 보상 연출 z25, 시트 z30, 토스트)으로 나뉜다 |
| 8 | 재화 칩 | 통과 | 골드 칩(코인 아이콘, 금액, 시간당 수입)과 별 칩. 유료 재화가 없어 (+) 구매 버튼은 두지 않는다. 금액 단위 `G`는 코인으로 바꿨다(#615). 화면 글자는 모두 공통 `Text`(components/GameUi)를 거쳐 금액 뒤 🪙를 같은 그림 코인으로 그린다. 메인 주 버튼, 목표 칩, 상점, 복귀 시트, 미션, 각 시트, 토스트, 보상 입자가 모두 해당한다(#617, #618). react-native `Text`를 화면 파일에서 직접 쓰지 않는지 테스트가 지킨다 |
| 9 | 예외 기록 | 해당 없음 | 사용자가 재료 생략(미니멀)을 고른 항목은 없다. 2번의 팝업 프레임은 생략 예외가 아니라 승인된 범위 밖 항목이다 |
