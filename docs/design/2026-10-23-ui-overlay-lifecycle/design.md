## 목적과 결정

첫 수확 축하 카드와 NEW CROP 배너, 토스트가 Continue를 가리지 않게 순서를 조정한다. 복귀 요약의 주 버튼 앞에는 기록 불러옴 토스트를 겹치지 않는다. 초기화 직후 온보딩이 끝나기 전 출석 시트를 자동으로 열지 않는다. 기능 완료 전에 배지를 지우는 방식으로 문제를 숨기지 않는다.

서로 다른 시트 또는 다른 콘텐츠를 열 때 스크롤을 위로 초기화한다. 같은 시트 내부의 사용자 조작과 입력은 보존한다. 기존 자동 완료 시간과 보상을 바꾸지 않는다.

## 흐름, 구조와 실패 처리

FarmGame의 activeSheet 및 overlay 수명주기, SheetParts의 ScrollView와 관련 component key를 대상으로 한다. 중복 전역 overlay 관리 계층을 추가하지 않고 기존 상태 전환을 고친다. 타이머와 subscription은 시트 닫기와 unmount에 해제한다. 로컬 테스트 저장만 초기화한다.

## 변경 범위의 인수조건과 실행

신규 첫 수확에서 즉시 Continue 탭, 자동 완료 8초 전후, toast 연속 표시, 복귀 요약, 출석 조건 충족 상태에서 reset, 시트 스크롤 후 다른 시트 열기와 재열기, 닫은 뒤 타이머 도착, 작은 화면 및 큰 글자를 실제 입력으로 확인한다. 기존 검수의 1회차 항목 11과 12, R2-5를 같은 상태로 재현한 전후 근거를 남긴다.

각 원 인수조건은 구현 PR에서 AC-번호로 순서대로 옮겨 실패와 통과 근거에 연결한다. 공개나 외부 운영 확인은 Refs로 남기고 코드 병합만으로 닫지 않는다. #575는 시작 화면, 상태와 접근성, 겹침으로 나누며 개인정보 항목은 조사 보류다. 범위 밖 항목은 원 이슈에서 유지한다.

### 접수 이슈의 원 인수조건

원 이슈의 기능 및 접근성 항목을 아래 분할 범위에 따라 검증한다.

위 원문 중 SDK 0.5.0, Firebase Remote Config, 배포 및 기기 검증 등 현재 구조 또는 이번 요청과 달라진 항목은 이 문서의 목적과 결정에서 차이를 밝혔으며 자동 충족으로 표시하지 않는다. 원문을 수정된 인수조건으로 몰래 대체하지 않는다.
